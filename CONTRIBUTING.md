# Contributing to S3 Browser-lite

## Development Workflow
1. Fork & branch
2. Install deps with `npm install`
3. Run with `npm run dev`
4. Test locally before PR

## Coding Standards
- TypeScript everywhere
- React functional components
- TailwindCSS for styling
- No AWS calls in renderer

## Best Practices
- Never log AWS creds
- Use pagination
- Secure IPC only
